# Quick Start Guide

## First Time? Do This:

### Step 1: Open the App
- The app loads at your development URL

### Step 2: Click "Setup Demo Data"
- Click the button at the bottom of the login page
- Wait for the green success message
- You'll see demo credentials

### Step 3: Login as Super Admin
```
Email: superadmin@church.com
Password: Admin@1234
```

### Step 4: You're In!
- See the dashboard with all church data
- Go to Members to see demo members
- Click on a member to see contributions
- Go to Admin Users to create more admins

---

## Try These Features:

### 1. Add a New Member
- Click Members → Add Member
- Fill in details → Create
- Member appears in list

### 2. Record Contributions
- Click on any member
- Scroll down to contribution table
- Click any cell to edit
- Type amount → Save

### 3. Export Members
- Click Members page
- Click CSV or PDF button
- File downloads automatically

### 4. Create a Church Admin
- Go to Admin Users
- Click "Add Admin"
- Name: John Doe
- Email: john@church.com
- Password: Test@123
- Role: Church Admin
- Church: St. Mary's Church
- Create Admin

### 5. Create Super Admin
- Same as above
- Role: Super Admin
- No church selection needed

### 6. View Activity Log
- Click Activity Logs (Super Admin only)
- See all actions in system
- Filter by Create/Update/Delete

| Edit Member | Click member → Edit button → Update |
| Delete Member | Check box → Delete button → Confirm |
| Record Contribution | Click member → Edit table → Save |

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Can't login | Use demo credentials or click Setup Demo Data again |
| Can't see members | Make sure you're logged in and on Members page |
| Contribution won't save | Click "Save Changes" button after editing |
| Can't add admin | Make sure all required fields filled and role selected |
| Can't see Activity Logs | Must be Super Admin (not Church Admin) |

## Pro Tips

1. **Search for members** - Use search bar at top to find by name
2. **Group by family** - Click family number to see all members
3. **Compare months** - Use year selector in contributions table
4. **Audit changes** - Check Activity Logs to see who did what
5. **Backup data** - Export CSV/PDF regularly for backups
